# IndustryConnect – Academia-Industry Collaboration Portal

**IndustryConnect** is a web-based platform designed to bridge the gap between students and industries by connecting students with recruiters and providing better internship and placement opportunities.

The platform helps students showcase their academic qualifications and certifications while allowing recruiters to identify suitable candidates based on industry requirements.

## 🚀 Features

### 👨‍🎓 Student Module
- Student registration and login.
- Create and manage student profiles.
- Add academic qualifications and certifications.
- Explore suitable job opportunities.
- View certification-based job matching percentages.
- View, accept, or decline offer letters.

### 🏢 Recruiter Module
- Recruiter registration and login.
- Create recruiter profiles.
- Post job opportunities.
- View student profiles and certifications.
- Identify suitable candidates based on certification matching.
- Rank candidates based on matching percentages.
- Send offer letters to selected students.

## ⚙️ How It Works

1. Students and recruiters register on the platform.
2. Students add their academic details and certifications.
3. Recruiters post job opportunities with required certifications.
4. The system compares student certifications with job requirements.
5. A matching percentage is calculated.
6. Recruiters can identify suitable candidates.
7. Recruiters can send offer letters to selected students.

### 📊 Skill Matching Formula

The platform calculates the matching percentage using:

`Matching Percentage = (Matched Certifications / Total Required Certifications) × 100`

For example, if a job requires four certifications and a student has three matching certifications, the matching percentage is **75%**.

## 💻 Installation and Setup

1. Clone this repository:

   `git clone <https://github.com/manojsudarsanam-pixel/manojsudarsanam.github.io>`

2. Open the project folder.

3. Make sure the following files are available:
   - `index.html`
   - `style.css`
   - `script.js`

4. Open `index.html` in your browser.

No backend installation or database setup is required for the current version.

## ⚠️ Current Limitations

- The current version uses browser LocalStorage for data storage.
- Data is not automatically synchronized across different devices.
- Authentication is implemented for demonstration purposes and is not production-secure.
- The OTP feature uses a demo verification code rather than real SMS verification.
- Skill matching is based on certification comparison, not an AI/ML model.
